\# My Blog 个人博客系统



\## 项目简介

基于 SpringBoot + Vue3 + MyBatis + MySQL 的个人博客系统，支持用户注册登录、文章发布与管理、分类筛选等功能。



\## 技术栈

\- 后端：SpringBoot、MyBatis、JWT、BCrypt

\- 前端：Vue3、ElementPlus、Axios

\- 数据库：MySQL



\## 功能列表

\- 用户注册 / 登录（JWT 认证，BCrypt 密码加密）

\- 文章发布、列表、详情、编辑、删除

\- 分类管理

\- 权限控制（只能编辑/删除自己的文章）

\- 全局异常处理

\- 参数校验



\## 快速开始

\### 后端

1\. 导入数据库脚本

2\. 修改 application.yml 数据库密码

3\. 运行 BackendApplication



\### 前端

1\. cd frontend

2\. npm install

3\. npm run dev
